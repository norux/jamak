# Testing Jamak

## Default checks

```sh
npm ci
npx playwright install chromium
npm run verify
```

`verify` runs Biome, application and platform-independent type checks, the Chrome build, unit/fixture tests and the controlled-clock caption browser check. It does not establish real model accuracy or native Chrome feature availability. Build output is `apps/chrome/dist`.

`npm test` runs `test:js` and `test:captions-stability`. Package scripts retain the release, speaker and live conversation checks listed below, plus `test:conversation` to serve the manual fixture. The former `test:framework:*` aliases and their aggregate runner are removed; individual unit and browser harnesses remain available. For a focused check, run `node --import tsx --test tests/<name>.test.ts` or `node --test tests/<name>.test.mjs`; run browser harnesses directly with `node tests/<name>.mjs` and their existing flags, for example `node tests/framework-chrome-tab-engine.mjs --capture-loss`. Use `node --import tsx tests/framework-chrome-replay.mjs` for the replay harness. Run type checks separately when needed. Dated reports under `docs/verification/` preserve the commands used at the time.

## Isolated manual development

Run `npm run dev` after installing Playwright Chromium. The command builds/watches into `.ralph/dev/extension`, serves the checked-in conversation fixtures at `http://127.0.0.1:8790`, and opens headed Chrome for Testing with the development extension loaded, one window containing only the Japanese player. Do not enable account synchronization in the test profile. The command uses the harness's official browser-component cache at `.ralph/media-framework/chrome-translation-components`; first-time local speech/translation pack preparation can require downloads. It neither copies personal profile data nor starts translation/playback automatically.

Select Japanese and prepare/start Jamak on the player tab, then play the audio. Compare Chrome translation against Advanced → Hy-MT2 on the same clip. Check Korean changing within the first spoken turn, final meanings against the expandable reference text, and Stop removing the overlay without late captions. Source rebuilds retain manual extension reload: open `chrome://extensions` when needed; restart for Vite configuration changes. Ctrl+C or closing the test browser ends the owned watcher/server/browser, while the profile and model cache survive. An occupied port 8790 fails without closing its owner; stop a separate fixture server before launching dev. Keep simultaneous real-inference checks separate to avoid GPU/focus interference.
