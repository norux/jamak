Jamak은 현재 탭의 음성과 이미지 속 글자를 기기 안에서 분석해 한국어·영어·일본어 자막과 번역으로 보여주는 Chrome 확장 프로그램입니다. API 키나 별도 앱 없이 사용할 수 있습니다.

음성 자막
• 현재 탭에서 재생되는 오디오를 실시간으로 인식하고 번역합니다.
• 영어·일본어·한국어 입력을 직접 선택하거나 언어 자동 감지를 켤 수 있습니다. 기본 입력 언어는 영어입니다.
• 자막 언어를 한국어·영어·일본어 중에서 선택할 수 있으며, 입력과 출력 언어가 같으면 원문을 표시합니다.
• 화자별 배경색, 전체화면 자막과 별도 원문·번역 기록 창을 제공합니다.

새로운 이미지 번역
• 이미지 탭에서 현재 페이지의 모든 이미지를 분석하거나 번역할 이미지 하나를 선택하세요.
• 원문 언어를 자동으로 판별하고, 원본 이미지를 유지한 채 글자가 있는 위치에 번역을 표시합니다. 별도 분석 탭을 열지 않습니다.
• 번역 자막을 드래그해 옮기고, 옆의 연필 버튼으로 원문과 번역을 수정할 수 있습니다. 이동한 자막은 되돌리기 버튼으로 원래 위치에 복원합니다.
• 다섯 단계 글자 크기, 자막 숨기기·다시 표시하기와 PNG 저장을 지원합니다.
• PP-OCRv5 Mobile, PP-OCRv6 Small·Medium 중에서 이미지 문자 인식 모델을 선택할 수 있습니다.

모델 준비와 사용
확장 팝업의 오디오·이미지 탭을 선택해 사용하세요. Advanced에서는 각 모델의 사용 범위를 확인하고 모델을 선택할 수 있습니다. 오디오·번역·OCR 준비는 하나의 진행 상태와 중지·재시도 버튼으로 관리합니다. 창을 닫아도 준비가 계속되며, 완료되면 Chrome 알림으로 알려드립니다. 다운로드한 파일은 재사용하고, 준비 실패 시 로딩한 모델 자원은 정리합니다.

개인정보와 제한
음성 인식·OCR·언어 판별·번역·PNG 생성은 기기 안에서 실행합니다. 이미지, 탭 캡처, 음성, 추출한 글자와 번역을 외부 추론 서버로 보내지 않습니다. 처음 사용할 모델과 Chrome 언어 팩의 다운로드에는 인터넷 연결이 필요합니다.

데스크톱 Chrome 138 이상이 필요하며, 기기·Chrome의 로컬 API와 언어 팩 지원에 따라 사용 가능 여부와 속도가 달라집니다. Whisper FP16과 Hy-MT2 모델은 WebGPU·FP16을 요구합니다. 인식·번역에는 지연과 오류가 있을 수 있습니다. 잡음·겹친 음성·짧은 발화나 문구·손글씨에서 정확도가 낮아질 수 있으며, 고정밀 OCR 모델이 항상 더 정확한 결과를 보장하지는 않습니다.

이미지 분석은 현재 문서의 표시된 img 이미지를 대상으로 하며 CSS 배경, iframe 속 이미지와 이후 추가된 이미지는 포함하지 않습니다. 일부 외부 이미지는 보이는 화면을 캡처하므로 잘리거나 다른 요소에 가려질 수 있습니다. 영어·일본어 인쇄 글자를 중심으로 검증했으며 손글씨와 한국어 원문 OCR의 정확도는 보장하지 않습니다.

마이크·시스템 전체 오디오·모바일 Chrome은 지원하지 않습니다. Chrome 내부 페이지 등 제한된 페이지에는 자막을 표시할 수 없습니다. 자세한 사용법과 개인정보처리방침은 프로젝트 홈페이지에서 확인할 수 있습니다.
