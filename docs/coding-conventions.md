# Coding conventions

- Use TypeScript with the existing strict compiler settings. Follow surrounding double quotes, semicolons and imports; Biome checks the repository.
- Prefer plain functions, narrow types and shallow control flow. Keep worker/feature helpers near their caller. Introduce shared abstractions only when independent callers need them.
- In automatic sessions, route translation by each transcript revision’s detected language. Never emit `auto` as a transcript language, infer language solely from a speaker ID, or translate a source whose language already matches the selected subtitle language.
- Keep recognition/translation/detection/speaker settings and subtitle language independent and frozen per preparation. Advanced model selection must dispose the previous session; language-only changes before capture reuse resident models and replace the frozen language snapshot. Both flows must preserve completed caches and never initiate tab capture. Explicit model/backend errors must not silently fall back.
- Keep browser globals in platform adapters. `packages/core` and `packages/contracts` must remain platform independent.
- Carry session identity, epoch and revision through asynchronous work. Reject stale results and release resources on cancellation, Stop and target loss.
- Bound audio, translation and transport queues. A normal burst of final results must preserve unread captions; do not silently reset the overlay to solve backpressure.
- Keep speaker inference independent of recognition and caption deadlines. Never upload voice embeddings or captured audio.
- Measure and acknowledge each stacked caption independently. Only fully visible rows accrue reading time; removing an older row must not restart a newer row’s clock.
- Streaming translation chunks must retain exact source/session identity, use increasing translation revisions and remain provisional until generation completes for that source revision. Completed generation flushes the presentation cadence immediately even if recognition remains provisional; caption retirement also requires final recognition. New source revisions reset translation completion, not the translation revision watermark.
- Streaming queues validate incoming ASR separately from the published source. Pin the active source while its translation streams, coalesce newer same-language corrections, and publish the latest replacement for the next job. Language corrections and same-language bypass publish immediately. Assign one published translation revision sequence to both translator chunks and same-language bypass; reject duplicate/backward producer revisions within a stream.
- Preserve visible text during correction. Use actual displayed text for reading acknowledgements and offset corrections. Hold regenerated prefixes of a replacement translation until they extend the existing sentence verbatim or generation completes; initial streams and language changes stay immediate. Patch the existing text node between its common prefix/suffix rather than recreating unchanged text.
- Retire a row only after its latest source and matching translation are final and read. Newer captions must not expire provisional rows; pending corrections must hold even a previously final displayed pair and grant final reading time when the corrected pair arrives.
- Translation finality means generation completed for that source revision, independently of recognition finality. Reuse a completed exact-text/language pair when recognition only confirms it; changed text still requires translation. Native pause-separated spans finalize only after the same text appears again behind a measured speech boundary; the open span stays provisional.
- Explicitly withdraw provisional hypotheses removed by recognition corrections. Carry a newer final empty `retracted` revision through the existing source channel, remove it from overlay/history, and fence late replies. Do not invent final text or age out an active correction to unblock the stack.
- Add regression checks for bugs before fixing them. Test behavior rather than private implementation details; do not export helpers solely for tests.
- Keep feature changes scoped. Do not rename compatibility keys or reformat unrelated files as a side effect.
- Language/model select controls share `apps/chrome/select.css`. Use Norux semantic roles mapped to existing Jamak theme variables; retaining the purple accent and system font is an intentional product override. Style the native `base-select` picker, options and selected/checkmark/focus states without adding selection JavaScript or new dependencies. Keep 44px targets and native labels, keyboard behavior, change events and disabled states.
- Follow [AGENTS.md](../AGENTS.md)'s required README/AGENTS/docs review whenever behavior changes. Update support tables only when a platform is actually supported.
- Use Conventional Commits, with one intent per commit. Record verification and any meaningful limitations.

- Audio language detection consumes original PCM before transcription; general text decision models are not audio classifiers. Preserve PCM when passing it to the independent detector, pin its graph/label mapping and reject stale decisions on Stop. Treat detector timing separately from total ASR and visible-caption delay.
