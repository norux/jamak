선택한 모델은 아래의 공통 준비 과정에서 함께 다운로드·검증합니다. 이미지의 원문 언어는 Chrome 로컬 텍스트 분류기로 자동 판별합니다.

모든 모델은 기기 안에서 실행됩니다. 모델을 선택하면 오디오·번역과 OCR을 하나의 과정으로 준비합니다. 단계별 진행 상태는 아래에서 확인할 수 있습니다.

번역 모델은 오디오·이미지가 공유합니다. 모델 변경 시 진행 중인 오디오를 중지하며, 번역·OCR 변경 시 이미지 분석도 중지합니다. 준비가 끝나면 원래 탭의 Jamak 팝업에서 번역을 다시 시작하세요.

선택한 모델 전체 준비가 완료되면 Chrome 알림을 보냅니다. 창을 닫아도 준비가 계속됩니다.
